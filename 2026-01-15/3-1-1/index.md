# SaaS 서비스 비교 분석하기

## 평소 사용하는 서비스가 SaaS인지 분류하고, IaaS/PaaS/SaaS의 차이를 이해합니다.

1. discord / youtube / notion / netflix / programmers
   1. SaaS 특징
      - 웹 기반(브라우저 있으면 접속가능)
      - 구독 모델(월/연 단위 요금 지불)
      - 자동 업데이트(항상 최신 버전)
      - 클라우드 저장(데이터가 서버에 저장)
   2. “웹 기반 서비스형 소프트웨어”라는 공통 특성을 가지고 있다
      - discord: 협업
      - youtube: 콘텐츠스트리밍
      - notion: 문서 협업
      - netflix: 구독형 콘텐츠
      - programmers: 교육
   3. Netflix SaaS 3가지 특징
      1. 소프트웨어 제공
      2. 구독형 요금 모델
      3. 사용자별 기능 상태 유지
